// 열린데이터광장 「인증키 사용」 안내 오픈API를 통해서 1회 호출시 최대 1,000건만 요청 가능하며 … ( 호출 횟수 제한은 없습니다. ) 실시간 지하철 오픈API는 1일 1,000회만 호출 가능 (인증키 1개당) └─ 활용사례(갤러리) 등록·승인 시 제한 없이 사용
“1,000건”은 하루 한도가 아니다. 1회 호출당 최대 응답 건수이고, 개발계정·운영계정 같은 등급 구분도 없다.
이 서버는 카탈로그 검색만 호출한다. 실시간 지하철 API가 아니므로 어느 제한에도 걸리지 않는다.
인증키가 소진될 일이 없다. 토큰을 나눠 주던 이유가 사라졌다 — 누구나 URL만 등록하면 쓴다.
제한의 목적은 서버 보호. IP당 60회/분 · 2,000회/일. 지키는 대상은 인증키가 아니라 머신이다.

한도에 걸려도 막지 않고 알려준다 — HTTP 429 · Retry-After로 재시도 시각을 함께 반환한다.
