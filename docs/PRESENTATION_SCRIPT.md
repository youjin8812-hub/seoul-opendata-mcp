# SOM 발표 스크립트 (목표 4분 30초 / 16슬라이드)

- **총 분량**: 약 1,330자 · 낭독 기준 **4분 20초~4분 30초** (슬라이드 전환 호흡 포함)
- **속도 기준**: 분당 300자(초당 5자). 평소 말이 빠르면 4분 10초, 느리면 4분 40초.
- **넘김 원칙**: 슬라이드 03·05·08은 **한 호흡에 빠르게** 넘어갑니다. 시간이 밀리면 `[생략가능]` 표시된 문장부터 뺍니다.
- **강조 표기**: **굵게** = 또박또박 눌러 읽기, `/` = 짧은 쉼, `//` = 한 박자 쉬고 슬라이드 전환.

## 01 표지 — Seoul Open-data MCP `12초`

안녕하십니까. 서울시 열린데이터광장 MCP, / 줄여서 **SOM**을 소개하겠습니다.
데이터를 **찾는 시간**을 / **만드는 시간**으로 돌려주는 도구입니다. //

## 02 현황 · Scale — 8,266건 `14초`

서울은 이미 **8,266건**, / 국내 최상위 규모로 데이터를 열어 두었습니다.
부산 다음이고, 뉴욕과 런던보다 많습니다.
그러니까 / **문제는 양이 아닙니다.** //

## 03 현황 · Who publishes `8초` ⚡빠르게

본청이 64퍼센트, 자치구가 26퍼센트입니다.
**등록 주체가 흩어져 있다**는 것만 기억해 주십시오. //

## 04 현황 · Supply ≠ Demand `18초`

그런데 / 많이 **가진** 분야와 많이 **쓰이는** 분야가 다릅니다.
보건이 1,800건으로 가장 많이 열려 있지만, / 실제 이용은 **교통과 환경 두 분야가 95퍼센트**를 가져갑니다.
나머지는 거의 쓰이지 않습니다. //

## 05 현황 · Freshness `12초` ⚡빠르게

게다가 **23.5퍼센트**는 1년 넘게 갱신이 없습니다.
목록에 있다고 / **살아 있는 데이터가 아닙니다.** //

## 06 문제 01 — 검색어를 맞혀야 한다 `18초`

여기서부터가 문제입니다. / 검색은 **이름을 아는 사람에게만** 열려 있습니다.
"유동인구로 창업 입지를 분석하고 싶다" / 이 한 문장을 넣으려면 / 먼저 **정답 검색어를 맞혀야** 합니다.
생활인구인지, 격자데이터인지, 상권분석인지. //

## 07 문제 02 — 찾아도 API가 아니다 `14초`

찾았어도 **API가 아닐 수 있습니다.**
1만 6천여 개 서비스 중 바로 개발에 쓸 수 있는 오픈API는 **34퍼센트**뿐인데, / 목록에서는 형식이 보이지 않습니다. //

## 08 문제 03 — 갱신주기·한도 `10초` ⚡빠르게

갱신주기도, 호출 한도도 제각각이고, / 인증키 하나를 **팀 전체가 나눠 써야** 합니다. //

## 09 문제 04 — 발견의 문제 `12초`

결국 가장 큰 문제는 / **있는 걸 못 찾는다**는 것입니다.
**공급의 문제가 아니라 발견의 문제**입니다. //

## 10 Before · the loop — "인구" 507건 `26초` ★핵심

"인구" 한 단어에 **507건**이 쏟아집니다.
그중 실제 데이터셋은 84건, / 상위 다섯 건은 유동인구·실시간인구·그 영문판·외국인 체류인구·생활인구 — / **전부 다른 개념**입니다.
검색하고, 스크롤하고, 상세페이지 들어가고, 다시 검색어를 바꾸고. / 이 루프를 반복하다가 / 대부분은 여기서 끝납니다.
**"데이터가 없나 보네."** //

## 11 해결 · Solution — SOM `28초` ★핵심

그래서 만들었습니다.
**만들고 싶은 것을 한 문장으로 말하면**, / 8,266건 카탈로그를 실시간으로 뒤져 / **점수와 근거를 붙인 추천**을 돌려줍니다.
검색어를 추측할 필요가 없고, / 형식은 확정 판별되고, / 최종갱신일 순으로 **살아 있는 데이터를 먼저** 보여주고, / 왜 이 점수인지 **근거까지 문장으로** 함께 옵니다.
도구 다섯 개, 응답 **91밀리초**입니다. //

## 12 해결 · How it works `22초`

동작은 다섯 단계입니다.
아이디어를 넣으면 / **동의어까지 확장해** 키워드를 뽑고, / 카탈로그를 병렬 검색해 중복을 걸러내고, / 도메인·형식·갱신·최신성·지역 기준 **95점 만점**으로 점수를 매겨,
상위 후보를 **근거와 담당부서 연락처까지** 붙여 돌려줍니다. //

## 13 해결 · Zero setup `18초`

설치는 없습니다. / 인증키도 각자 받을 필요 없습니다.
**원격 서버가 이미 떠 있어서** URL 하나만 연결하면 됩니다.
Claude, Cursor, Claude Code 어디서든 커넥터로 등록하고 / **그냥 물어보시면 됩니다.** //

## 14 사례 · Before & After `30초` ★핵심

실제로 어떻게 달라지는지 세 가지만 보겠습니다.
상가 계약을 앞둔 창업자는 인허가 데이터를 뒤지다 **두 시간 만에 포기**했지만, / 이제 한 문장이면 **1분**입니다.
등하굣길 안전지도를 만들려던 학부모는 **반나절이 40초**로 줄었습니다. `[생략가능]`
따릉이 수요를 예측하려던 개발자는 이미 종료된 API를 붙잡고 있었지만, / 이제 **최신성 정렬로 죽은 API는 자동으로 뒤로** 갑니다. //

## 15 사례 · Summary `12초`

정리하면, / 검색어 추측이 **한 문장**으로, / 눈으로 하던 형식 판별이 **자동**으로, / 반복하던 탐색 루프가 **질의 한 번**으로 바뀝니다. //

## 16 마무리 — Thank you `16초`

**데이터가 없어서가 아니라 / 있는 줄 몰라서** 못 쓰던 문제를 풀었습니다.
여러분의 아이디어를 / 데이터 **찾는 시간**에서 / **만드는 시간**으로 돌려놓겠습니다.
감사합니다. //
